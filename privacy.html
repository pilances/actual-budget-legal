Datenschutzhinweise

Diese Anwendung wird ausschließlich zur privaten Verwaltung eigener Finanzen betrieben und nicht Dritten als Dienst angeboten.

Die Finanzdaten werden in einer selbst gehosteten Actual-Budget-Instanz gespeichert. Zum Abruf von Bankkontoinformationen wird Enable Banking verwendet. Dabei werden im Rahmen der erteilten Bankautorisierung Kontoinformationen über Enable Banking abgerufen.

Diese Informationsseite wird über GitHub Pages gehostet. Beim Besuch können technische Zugriffsdaten durch GitHub verarbeitet werden.
